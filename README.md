# 📷 Lumix DMC-TZ100 Web Controller

Веб-интерфейс и API-прокси на базе **FastAPI** для удалённого управления фотоаппаратом **Panasonic Lumix DMC-TZ100** и высокоскоростного скачивания оригинальных медиафайлов (**RAW `.RW2`**, **JPEG** и **4K-видео `.MP4`**) по Wi-Fi с ПК без использования мобильного приложения *Panasonic Image App*.

---

## 🚀 Основные возможности

- **Live View в браузере (с Fullscreen-режимом):** захват UDP-видеопотока с камеры (порт `49152`), сборка JPEG-кадров на лету, трансляция в браузер по протоколу `MJPEG` с фоновым поддержанием сессии (`keepalive`) и разворот видоискателя на весь экран (`Fullscreen API`).
- **Полное управление съёмкой:** спуск затвора, старт/стоп видеозаписи, управление оптическим зумом (`Wide` / `Tele`), переключение режимов (`recmode` / `playmode`) и индикация заряда аккумулятора.
- **Динамическое меню настроек (RU):** автоматический парсинг заводской спецификации `tz100_allmenu.xml` с официальной русской локализацией (ISO, экспокоррекция, баланс белого, формат/качество фото и видео, режимы автофокуса и серийной съёмки).
- **Быстрая DLNA-галерея с пагинацией:** чтение содержимого SD-карты через `UPnP / SOAP` (порт `60606`) пачками по 45 файлов с конца флешки (кнопка «Загрузить ещё 45») и последовательной очередью загрузки миниатюр без перегрузки однопоточного сервера камеры.
- **Скачивание оригинальных RAW (`.RW2`) и 4K-видео (`.MP4`):**
  - Обход искусственной блокировки прошивки (`copy_to_sp="no"`) для тяжелых 4K `MP4` (100 Мбит/с) и сырых `RAW`.
  - Автоматическая подмена фейковых DLNA-ссылок (`DO...JPG` с `size="0"` и типом `UNKNOWN_DATA`) на прямые пути к оригиналам `DO...RW2` (~22.2 МБ).
  - Ручной парсер `Transfer-Encoding: chunked` через `http.client` на порту `50001`, полностью исключающий артефакты, битые байты и зависания сокета в конце потока.
- **Пакетное скачивание (Batch Download):** выделение карточек чекбоксами (по клику на превью или кнопками «Выбрать все» / «Снять выбор») и последовательная выгрузка выбранных файлов на ПК в 1 клик.

---

## 🛠 Технологический стек

- **Backend:** Python 3.10+, FastAPI, Uvicorn, python-dotenv
- **Сеть и протоколы:** HTTP CGI API (порт `80`), UDP Socket (видеопоток `49152`), UPnP / DLNA SOAP (`60606`), HTTP File Server (`50001`), `requests`, `http.client`, `urllib`
- **Парсинг данных:** `xml.etree.ElementTree` (DIDL-Lite XML, Camera Menu XML)
- **Frontend:** Vanilla JS (ES6+, Fullscreen API), HTML5, CSS Grid / Flexbox (тёмная тема без внешних зависимостей)
