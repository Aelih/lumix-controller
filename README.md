# 📷 Lumix DMC-TZ100 Web Controller

Веб-интерфейс и API-прокси на базе **FastAPI** для удалённого управления фотоаппаратом **Panasonic Lumix DMC-TZ100** и высокоскоростного скачивания медиафайлов (включая 4K-видео) по Wi-Fi с ПК без использования мобильного приложения *Panasonic Image App*.

---

## 🚀 Основные возможности

- **Live View в браузере:** захват UDP-видеопотока с камеры (порт `49152`), сборка JPEG-кадров на лету и трансляция в браузер по протоколу `MJPEG` с фоновым поддержанием сессии (`keepalive`).
- **Полное управление съёмкой:** спуск затвора, старт/стоп видеозаписи, управление оптическим зумом (`Wide` / `Tele`), переключение режимов (`recmode` / `playmode`) и индикация заряда аккумулятора.
- **Динамическое меню настроек (RU):** автоматический парсинг заводской спецификации `tz100_allmenu.xml` с официальной русской локализацией (ISO, экспокоррекция, баланс белого, формат/качество фото и видео, режимы автофокуса и серийной съёмки).
- **Быстрая DLNA-галерея с пагинацией:** чтение содержимого SD-карты через `UPnP / SOAP` (порт `60606`) пачками по 45 файлов с конца флешки и последовательной очередью загрузки миниатюр без перегрузки однопоточного сервера камеры.
- **Прямое скачивание 4K-видео и фото в 1 клик:** обход искусственного ограничения мобильного приложения (`copy_to_sp="no"`) для тяжелых `MP4` (100 Мбит/с) и обход бага прошивки с некорректным заголовком `Transfer-Encoding: chunked` на порту `50001`.

---

## 🛠 Технологический стек

- **Backend:** Python 3.10+, FastAPI, Uvicorn
- **Сеть и протоколы:** HTTP CGI API (порт `80`), UDP Socket (видеопоток `49152`), UPnP / DLNA SOAP (`60606`), HTTP File Server (`50001`), `requests`, `urllib`
- **Парсинг данных:** `xml.etree.ElementTree` (DIDL-Lite XML, Camera Menu XML)
- **Frontend:** Vanilla JS (ES6+), HTML5, CSS Grid / Flexbox (без внешних зависимостей)
